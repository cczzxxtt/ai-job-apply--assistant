# AI求职助手 v1.0

面向应用化学本科应届生，目标深圳、广州、上海。

## 功能
- 工作台与岗位匹配排序
- DuckDuckGo 搜索候选岗位（搜索结果不是实时招聘状态保证）
- 手动录入岗位
- SQLite 岗位数据兼容旧版 v0.2/v0.3 数据库结构
- CSV 导入导出
- 岗位信息分析与投递建议
- 求职材料提示词生成：岗位定制简历、HR开场白、求职邮件、自我介绍、面试准备
- 投递状态管理

## 部署
主文件 `app.py`；依赖 `requirements.txt`。
Streamlit Cloud 的 Main file path 应设置为 `app.py`。

## 数据与隐私
数据库使用本地部署实例 SQLite `jobs.db`。云端实例的数据持久性不保证，定期导出CSV备份。
简历上传控件仅用于当前会话，不写入数据库。该版本不使用AI API，不自动提交申请，不绕过招聘平台规则。

## 注意
搜索候选需打开原招聘页确认公司、具体岗位、学历/专业/经验、薪资、招聘状态和申请链接。规则匹配分数不等于录取概率。
