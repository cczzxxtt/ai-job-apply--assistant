# AI求职助手 v2.0 企业监控版

针对应用化学本科应届生，目标深圳、广州、上海。

## v2.0新增
- 导入此前的100家目标企业名单（34深圳、33广州、33上海）
- 企业库按城市和优先级筛选
- 企业招聘官网链接字段（可手动维护）
- 企业定向搜索：按企业+城市+岗位关键词查询
- DuckDuckGo网页搜索，失败时Bing RSS备用
- 候选结果去重入库、匹配评分、风险提示
- 候选岗位加入待投递队列、标记不合适/已核实
- 投递跟踪与CSV导出备份

## 重要限制
- 搜索结果只是公开网页候选，不保证招聘仍开放或确属该公司岗位；请打开原网页核实。
- 本版不自动投递、不绕过网站登录/验证码/限制。
- Streamlit Cloud上的SQLite数据可能不持久，建议定期导出CSV。
- 每次建议先搜索5家企业，控制搜索量。

## 部署
- 主文件：app.py
- requirements.txt
- Streamlit Cloud Main file path: app.py
- 企业名单：companies.csv（与app.py同目录）
