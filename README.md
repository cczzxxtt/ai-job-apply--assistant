# AI求职助手 v0.2

面向应用化学本科应届生，求职城市深圳、广州、上海。

## v0.2 新功能
- 公开搜索引擎招聘信息搜索（实验版）
- 多城市、多岗位方向搜索
- 搜索候选结果去重保存
- 初步匹配分（仅根据标题和摘要）
- 选中候选岗位后加入投递管理，默认标记“待核实”
- 保留 v0.1 的手动录入、CSV导入、投递跟踪、CSV导出

## 部署
Streamlit Community Cloud 使用 GitHub 仓库的 `app.py` 作为入口。上传本项目的 `app.py`、`requirements.txt`、`README.md` 覆盖/更新仓库根目录文件即可。

## 注意
公开搜索结果可能过期、重复或不完整。所有招聘状态、公司、学历、专业、经验、薪资和申请链接都必须打开原网页核实。此版本不自动登录、不自动投递。
